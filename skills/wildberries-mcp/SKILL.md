# Wildberries через MCP

Ставит сервер `wildberries-mcp-ru`: 307 методов официального API
(чтение 187, запись 108, необратимое 12). Каталог методов лежит в YAML и
исполняется сервером, поэтому агент получает несколько универсальных
инструментов, а не по отдельной функции на каждый метод.

## Установка

Пакет на PyPI, поэтому строка одна:

```bash
uvx wildberries-mcp-ru
```

Если нужна ветка `main`, а не релиз:

```bash
uvx --from git+https://github.com/ilyautov/wildberries-mcp-ru wildberries-mcp-ru
```

Конфигурация клиента (Claude Desktop, Cursor, Claude Code):

```json
{
  "mcpServers": {
    "wb": {
      "command": "uvx",
      "args": ["wildberries-mcp-ru"],
      "env": {
        "WB_API_TOKEN": "<значение>"
      }
    }
  }
}
```

## Где взять ключи

- `WB_API_TOKEN`: Токен из кабинета seller.wildberries.ru, Настройки → Доступ к API. Уходит в Authorization без Bearer.

Второй путь, без переменных окружения: поднять сервер и вызвать
`wb_add_cabinet`. Ключи лягут в `~/.marketplace-mcp/cabinets.json`
с правами 600 и с машины не уходят. Так же подключается второй магазин.

## Что спрашивать у сервера

- `wb_search_methods("остатки по складам")`: поиск метода словами.
- `wb_describe_method(...)`: параметры, пагинация, класс доступа.
- `wb_call_method(...)`: вызов. Чтение идёт сразу, запись просит
  подтверждения, необратимое просит дважды.
- `wb_check_auth`: проверить, что ключи дошли.

## Как себя вести

Сначала ищи метод каталогом, не угадывай имя. Перед записью покажи человеку,
что именно уйдёт в API, и дождись согласия: гейт сработает всё равно, но
человек должен увидеть тело запроса до, а не после.

Числа из ответа не округляй и не пересчитывай в уме. Если метод вернул
пустой список, так и скажи, вместо того чтобы объяснять это за продавца.
